## 🚀 Getting Started

### Local Development

1. **Clone the repository**
```bash
git clone https://github.com/bhaveshamre/bhaveshamre.github.io.git
cd bhaveshamre.github.io
```

2. **Install dependencies (if using build tools)**
```bash
npm install  # If using Node.js build tools
```

3. **Start local server**
```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx http-server

# Using VS Code Live Server extension
# Right-click on index.html → Open with Live Server
```

4. **Open in browser**
```
http://localhost:8000
```

### Customization

- **Update Personal Info**: Edit the text in `index.html`
- **Change Theme**: Modify CSS variables in the `<style>` section
- **Add Projects**: Update the projects section in `index.html`
- **Modify Skills**: Edit the skills grid in the about section
